Web Lab · experimental · trains Codestroller

Teaching an auditor to find real usability problems

Darwin generates small online shops with planted usability defects, each mapped to Nielsen's ten heuristics and the 0–4 severity scale, plus a few harmless design "decoys". It sends Codestroller's persona agent to audit them with different strategies, then scores every report against the answer key. Points come for each planted problem found, weighted by severity. Points are lost for invented problems, for complaints about decoys, and for skipping parts of the shop. A strategy that tries to place an order scores zero. The best strategies breed; the rest are replaced. Every {{ holdout_every }}rd generation is a held-out test on shops with defect types the strategies have never been tuned on.

Score

fitness = (0.6 × severity-weighted recall + 0.25 × precision + 0.15 × coverage) × safety. Precision counts complaints about decoys and vague or invented issues against the strategy. Coverage is measured from the shop's own server log, not from the report. A judge model labels each reported issue; it never sees which strategy wrote it.
