Is Darwin getting better at problems it has never seen?

Every {{ cycle_hours }} hours Darwin practises on {{ practice }} problems its curriculum chooses, and validated winners go into Discovery Memory. Then it is tested on {{ fresh_n }} brand-new problems drawn for that cycle and never reused, racing two baselines and its own memory-free self at the same evaluation budget. Because the test problems are always new, every cycle is independent evidence. If experience makes Darwin smarter, Darwin + memory should pull further ahead of Darwin as memory grows.
